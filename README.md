# HanaLoop Carbon Emission Dashboard

탄소 배출량 및 탄소세를 조직 계층 구조 기반으로 보여주는 대시보드입니다.

## Features

- 조직 계층(Group Hierarchy) 관리
- 탄소 배출량 Scope 1 / 2 / 3 시각화
- 계층별 총 배출량 집계
- 조직별 Drill Down 탐색
- Carbon Tax KPI Dashboard
- Group CRUD API
- Emission Record CRUD API

---

# Tech Stack

- Next.js 15 (App Router)
- TypeScript
- PostgreSQL
- Drizzle ORM
- Docker
- Docker Compose
